# Partner inventory onboarding

Use `inventory-intake-template.csv` as the handoff sheet for the first Zadar operators. Use one row per experience. If one boat offers three tours, repeat the operator and boat fields on three rows.

## Formatting

- Separate multiple values with `|` (tags, amenities, inclusions, exclusions and image URLs).
- Enter prices in euros as decimal values; the importer will convert them to cents.
- Use 24-hour time labels in itinerary text.
- Use only photos the operator owns or is licensed to provide.
- Keep operator email, phone and internal notes private.
- Set every first import to `draft`.

## Verification call

Before publishing, confirm:

- legal operator/business name and public display name;
- boat registration, passenger capacity and skipper coverage;
- standard route, duration and realistic departure point;
- price, what fuel is included and possible additional charges;
- cancellation and bad-weather handling;
- season dates and known blackout periods;
- permission to display supplied photos and public profile;
- who receives booking requests and expected reply time.

The current website reviews remain presentation fixtures and are not part of the live inventory import.
